# Upstream research routes

Audience: maintainers upgrading or changing frameworks. Last inspected: 2026-09-13. These are official entry points, not evidence that their current contents were reviewed during this documentation task.

- [Node.js documentation](https://nodejs.org/api/): runtime/test/crypto APIs.
- [pnpm documentation](https://pnpm.io/): install and lockfile behavior.
- [Prisma documentation](https://www.prisma.io/docs): adapter, generation and migration compatibility.
- [mediasoup documentation](https://mediasoup.org/documentation/v3/): worker/transport/consumer lifecycle.
- [uWebSockets.js source](https://github.com/uNetworking/uWebSockets.js): request lifetime and binary compatibility.
- [Vite documentation](https://vite.dev/guide/): client build/proxy.
- [Electron documentation](https://www.electronjs.org/docs/latest/): IPC, packaging and security.
- [Docker Compose documentation](https://docs.docker.com/compose/): configuration/deployment behavior.
- [GitLab administration](https://docs.gitlab.com/administration/): Omnibus operations.

Read release notes for the exact version before important upgrades. Repository behavior remains grounded in checked-in source/config/tests. Related: [dependencies](../../docs/dependencies.md).
